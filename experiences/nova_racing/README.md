# NOVA Racing — Circuit Grand Prix

A fast-paced original 3D racing experience designed to test vehicle dynamics, collision boundaries, checkpoints, lap timing, and touch controls.

## Mechanics
- **Asphalt Circuit**: High-traction oval race track with banked turns and side barriers.
- **Vehicle Simulation**: Physics vehicle model simulating engine power, acceleration, steering sensitivity, and road friction.
- **Start / Finish Line**: Timing gate triggering lap start and finish.
- **Checkpoint Gates**: Progressive checkpoint gates around the track to prevent course cutting.
- **Lap Timer & Best Lap HUD**: Displays current lap duration, completed laps, and personal best time.
