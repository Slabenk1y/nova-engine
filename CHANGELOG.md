# Changelog

## [1.0.0] - Minimum Playable Platform Release
### Added
- Modular Cargo workspace comprising 12 engine crates and 4 experience packages.
- 3D physics engine with rigid bodies, character controllers, and vehicle simulation.
- Versioned JSON serialization for Places and multi-place experience manifests.
- Customizable block avatar rig and animation state machine.
- Visual node graph scripting system with sandboxed execution runtime.
- Authoritative multiplayer networking with room snapshot replication.
- Platform backend with user accounts, SHA256 authentication, catalog search, and persistence.
- Complete 9-tab platform navigation model and mobile touch virtual joystick.
- NOVA Creator Studio session with undo/redo stack and starter templates.
- 4 playable test experiences: NOVA Obby, NOVA Social World, NOVA Simulator, NOVA Racing.
- Automated Android build pipeline generating a signed, verified APK (`android/build/outputs/apk/nova-debug.apk`).
- Comprehensive documentation suite: ARCHITECTURE, ROADMAP, PROGRESS, TEST_REPORT, KNOWN_ISSUES, CHANGELOG, SECURITY.
